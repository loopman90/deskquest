Install For Testing

Build the plugin, then place the generated plugin files in your Obsidian vault.

  1. Download the latest release from GitHub.
  2. Copy main.js, manifest.json and styles.css to .obsidian/plugins/regen/
  3. Or use BRAT with https://github.com/loopman90/regen
  4. Enable Regen in Obsidian Community plugins.

Privacy And Safety

Regen is a gamified productivity and work-rhythm tool. Health, Stamina, Hydration and Food are fictional game indicators based on configured routines and activity. Regen does not provide medical advice.
