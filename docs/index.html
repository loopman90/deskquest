Install For Testing

Build the plugin, then place the generated plugin files in your Obsidian vault.

  1. npm install
  2. npm run build
  3. Copy main.js, manifest.json and styles.css to .obsidian/plugins/deskquest/
  4. Enable DeskQuest in Obsidian Community plugins.

Privacy And Safety

DeskQuest is a gamified productivity and work-rhythm tool. Health, Stamina, Hydration and Food are fictional game indicators based on configured routines and activity. DeskQuest does not provide medical advice.
