# DeskQuest v0.2.0

Expanded public starter release.

## Included

- Obsidian plugin scaffold with strict TypeScript
- DeskQuest statusbar HUD
- Dashboard view
- Health, Stamina, Hydration and Food game bars
- XP and level engine
- Work sessions with idle and sleep-gap handling
- Break, hydration, meal, snack and movement commands
- Daily quests and weekly goal starter data
- Settings tab with safe defaults
- 25 presentation-only skins
- JSON and CSV export commands
- GitHub Pages landing site
- First-run onboarding
- Active reminder state with snooze and dismiss actions
- Recovery, hydration, movement and eye-break reminder evaluation
- Import JSON command with validation
- Reset Today, Reset Game Progress and Reset Everything commands
- Safer export filenames
- Daily history panel

## Safety

DeskQuest is a gamified productivity and work-rhythm tool. Health, Stamina, Hydration and Food are fictional game indicators based on configured routines and activity. DeskQuest does not provide medical advice.
